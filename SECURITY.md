# Política de segurança

Não publique vulnerabilidades, dados de acesso ou material de cliente em issues públicas.

Para relatar uma vulnerabilidade técnica, abra uma comunicação privada com o mantenedor do repositório contendo:

- descrição objetiva do problema;
- impacto potencial;
- passos de reprodução com dados sintéticos;
- versão ou commit afetado;
- sugestão de correção, se houver.

O repositório não deve receber senhas, tokens, planilhas de usuários, perfis, templates internos ou diagnósticos reais.
